# Brainrot mode — style bible for the EP27-29 rewrites (Gen Alpha edition)

Gordon's brief (2026-08-28): "rewrite the scripts of episodes 27-29 in gen alpha brainrot
terms (dumb it down and use brainrot language). feel free to be slightly inappropriate and
chaotic. the visuals should also match (they should use brainrot images and characters)."

This file is the shared reference so every rewritten script and every overlay in the
brainrot episodes speaks the same dialect. The technical content must still be CORRECT —
the brainrot is the delivery, not the substance. Dumb the words down, never the idea.

## Voice rules

- Talk like a 12-year-old explaining it to another 12-year-old at 2x speed. Short
  sentences. Every beat gets at least one slang hit; the payoff line is pure brainrot.
- "Slightly inappropriate and chaotic" = PG-13 chaos: roasting, absurdity, mild crudeness
  (gyatt, huzz, "crash out", "ts pmo"), NOT sexual content, NOT slurs, NOT anything that
  would get the channel flagged. Baby Gronk is a real child — name-drop the meme only,
  never his image.
- Keep the series skeleton: HOOK / PROBLEM / BUILD / NEW COMPONENT / (AI ANGLE) /
  PAYOFF + NEXT, ~45-55s, two hook variants (A/B). The "NEXT" tease stays.
- Real technical term still gets said ONCE, plainly, right after its brainrot translation
  ("that's called a bug bounty, no cap") — so the video still teaches.

## Sourcing the visuals (during the build phase)

- Italian brainrot characters are AI-generated fan art with no single rights-holder;
  Gordon has said not to worry about rights for these. Pull transparent PNGs from the
  fan wikis (brainrotcharacters.net, playbrainrot.org/en/characters, the Fandom
  Gametoons wiki) via `curl -L -A "Mozilla/5.0"`; ffprobe-verify every file. Fallback:
  screenshot the wiki cards with the browser tools and cut out the character.
- Public-figure photos: Wikimedia Commons (Livvy Dunne, LaMelo Ball, Kai Cenat all have
  CC photos). No images of Baby Gronk (minor).
- Overlay treatment: SAME production rules as always (OVERLAY_SPEC.md, margins x70-870
  y200-1280, graphics never over text, two-act structure) — but the hero object is a
  brainrot character doing the system-design job, with meme-style Impact-font captions
  allowed INSIDE overlays (not the burned-in captions). Colour palette can go
  hyper-saturated. Deep-fried/saturation "turn" transitions are on-brand.
- SFX: this is where the TikTok set finally gets to go full send — vine boom, bruh,
  sheesh, "6 7" audio (source the Skrilla "Doot Doot" 6-7 snippet from myinstants),
  tung-tung-tung knock (myinstants has it), Tralalero "tralalero tralala" chant.
  Variety rules still apply; the voice-meme cap of one per episode is LIFTED for these.
